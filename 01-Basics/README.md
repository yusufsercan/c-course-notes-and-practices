# 📁 01-Basics

This folder contains my practice programs and solutions focused on the fundamental concepts of C programming language.

---

## 📜 Files & Descriptions

* **`01_circle_area_perimeter.c`** : Calculates the area and perimeter of a circle based on user-input radius.
* **`02_sum_of_digits.c`** : A basic-level example using a while loop to sum the digits of a number entered by the user and display the result on the screen.
* **`03_book_order_discount.c`** : A basic tiered discount calculation system for book orders.
* **`04_character_type_checker.c`** : Determines if a character is uppercase, lowercase, or non-alphabetic using ASCII bounds and interactive `while` loop control.
