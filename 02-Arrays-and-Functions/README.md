# 📁 02-Arrays-and-Functions

This folder contains my practice implementations and technical exercises focused on modular programming, function lifecycles, and array mechanics in C. The core objective is to master stack frame dynamics, parameter passing behavior, array decay, and contiguous memory structures before advancing to pure pointer arithmetic.

---

## 📜 Files & Descriptions

* **`01_basic_functions.c`** : Demonstrates basic function definitions, passing multiple arguments (strings and integers), and formatted console output.
* **`02_basic_functions_and_arrays.c`** : Demonstrates passing arrays to functions, function return values, and memory boundary safety using dynamic array sizing.
