# 🚀 C Course Notes & Practices

This repository contains C programming code examples, core memory concepts, data structures, and practical exercises developed during my coursework and self-study sessions.

> ⚠️ **Note:** The code in this repository represents my ongoing learning journey. The primary goal is to master procedural programming, memory management in C, and build a solid engineering foundation.

---

## 📁 Repository Structure

* **01-Basics:** Fundamental I/O operations (`printf` / `scanf`), data types, operators, conditional statements, and basic mathematical calculations.
* **02-Arrays-and-Pointers:** Array manipulation, memory addresses, pointer arithmetic, and string handling.
* **03-Functions-and-Memory:** Function prototypes, pass-by-value vs pass-by-reference, scope, and dynamic memory allocation (`malloc`, `calloc`, `free`).
* **04-Structures-and-Files:** `struct`, `union`, `typedef` declarations, and file handling operations (`fopen`, `fread`, `fwrite`).
* **05-Mini-Projects:** Console-based mini applications combining multiple core C programming concepts.
